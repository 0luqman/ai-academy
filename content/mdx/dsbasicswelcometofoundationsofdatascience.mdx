There are many different types of Data Scientists (some work mostly in SQL, others in Python, some do more statistics, while others focus on machine learning, etc.), but they all share the same core skillset. This path is all about those core skills. 


This is a great place to start if you know you want to work with data, but aren’t sure exactly what role you want to be in. It’s a great way to try out Data Science or quickly build the most universal and relevant data science skills.  


Finally, this Skill Path is the beginning (or Foundation) of all of our Data Scientist Career Paths, so if you are working towards a career as a data scientist, you can start here, decide on a specialization later, and your progress will transfer.


Whatever your goals, if working with data is on your list, then this is the Path for you!


### What will you learn?


In this Skill Path, you will develop the knowledge and skills you need to work with data confidently. It is a comprehensive introduction to the programming, analytical, and communication skills that are at the center of data science.


After this course, you will be able to:



- articulate what can go right and what can go wrong when working with data.

- query, manipulate, and analyze data in databases using SQL.

- write basic programs to create custom analyses with Python.

- clean data to prepare it for analysis.

- ask and answer questions using appropriate statistical measures.


This course is the foundation for all of our Data Scientist Career Paths and will prepare you for working with data in a professional setting. 


### Why did we make this?


We built this skill path to guide you through everything you need to know to work with data confidently. We have studied the data and worked with data scientists, analysts, managers, and professors to identify which skills are at the core of a data science education. We’ve pinpointed what skills are universal to all data professionals, and what skills are a little more niche. This Skill Path is those universal topics. 


After this Skill Path, you should be ready to apply data science to your professional, academic, or hobbyist goals, and move on to the Data Scientist Career Paths if you want to earn a job as a Data Scientist.


### What should you know before starting this course?


This course assumes that you have no prior experience working with data or programming (though it does assume interest and curiosity).

In this exercise, you will apply your knowledge of Python lists to organize medical insurance data. You will be using the `zip()` function to pair names with their respective insurance costs.

### Insurance Cost Calculator

Below is the base code for calculating insurance costs. We've estimated costs for Maria, Rohan, and Valentina.

```python
def estimate_insurance_cost(name, age, sex, bmi, num_of_children, smoker):
  estimated_cost = 250*age - 128*sex + 370*bmi + 425*num_of_children + 24000*smoker - 12500
  print(name + "'s Estimated Insurance Cost: " + str(estimated_cost) + " dollars.")
  return estimated_cost

# Estimate Costs
maria_cost = estimate_insurance_cost(name="Maria", age=31, sex=0, bmi=23.1, num_of_children=1, smoker=0)
rohan_cost = estimate_insurance_cost(name="Rohan", age=25, sex=1, bmi=28.5, num_of_children=3, smoker=0)
valentina_cost = estimate_insurance_cost(name="Valentina", age=53, sex=0, bmi=31.4, num_of_children=0, smoker=1)

# Organize Data
names = ["Maria", "Rohan", "Valentina"]
insurance_costs = [maria_cost, rohan_cost, valentina_cost]
insurance_data = list(zip(names, insurance_costs))
print("Current Insurance Data: " + str(insurance_data))
```

So far we have learned:



- How to create a dictionary

- How to add elements to a dictionary

- How to update elements in a dictionary

How to use a dict comprehension to create a dictionary [from](/learn)Preview: Docs Used to import specific attributes, classes, or functions from a Python module.

We are building a music streaming service. We have provided two lists, representing songs in a user’s library and the amount of times each song has been played.


Using a dict comprehension, create a dictionary called plays that goes through zip(songs, playcounts) and creates a song:playcount pair for each song in songs and each playcount in playcounts.

Print plays.

To print a dictionary in Python, you can use the print() function and pass the dictionary name as the argument.

After printing plays, add a new entry to it. The entry should be for the song "Purple Haze" and the playcount is 1.

You can add a new entry to a dictionary by using square brackets [] with the new key and assigning it a value. In this case, the key would be "Purple Haze" and the value would be 1.

This user has caught Aretha Franklin fever and listened to “Respect” 5 more times. Update the value for "Respect" to be 94 in the plays dictionary.

You can update the value of a specific key in a dictionary by referencing the key and assigning a new value to it. In this case, the key is the song title "Respect".

Create a dictionary called library that has two key: value pairs:



- key "The Best Songs" with a value of plays, the dictionary you created

- key "Sunday Feelings" with a value of an empty dictionary

Remember, to create a dictionary, you can use the {} syntax. You can then add key-value pairs inside this syntax, separating the key and value with a colon : and different pairs with a comma ,. For the "Sunday Feelings" key, you can assign an empty dictionary as its value by using {}.

Print library.

To print the library dictionary, you can use the built-in Python function print() and pass library as the argument.
